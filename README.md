# Telegram Thread Stats Bot

Бот рахує повідомлення користувачів окремо по гілках/топіках Telegram-чату: день, тиждень, місяць, загалом.

## Запуск

1. Встанови Python 3.10+
2. Створи бота через @BotFather і скопіюй токен.
3. У @BotFather вимкни Privacy Mode:
   `/setprivacy` → обери бота → `Disable`
4. Додай бота в групу/супергрупу з гілками.
5. Перейменуй `.env.example` у `.env` і встав токен.
6. Запусти:

```bash
pip install -r requirements.txt
python bot.py
```

Або на Windows відкрий `run.bat`.

## Команди

- `/top_day` — топ за день у всьому чаті
- `/top_week` — топ за тиждень у всьому чаті
- `/top_month` — топ за місяць у всьому чаті
- `/top_all` — топ за весь час у всьому чаті
- `/thread_day` — топ за день у поточній гілці
- `/thread_week` — топ за тиждень у поточній гілці
- `/thread_month` — топ за місяць у поточній гілці
- `/thread_all` — топ за весь час у поточній гілці
- `/me` — твоя статистика в поточній гілці

## Важливо

Бот рахує тільки нові повідомлення після запуску. Старі повідомлення Telegram Bot API не віддає.
